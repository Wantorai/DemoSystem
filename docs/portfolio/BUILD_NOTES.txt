ArtCoupe Manufacturing Software portfolio

Deliverable: Roman_Sidorenko_ArtCoupe_Portfolio.pdf
Format: six US Letter pages, American English, selectable text and contact links.
Editable document: Roman_Sidorenko_ArtCoupe_Portfolio.html (images embedded).

Rebuild from the repository root:
  node portfolio_work/build_recruiter_portfolio.cjs
  node portfolio_work/check_recruiter_portfolio.cjs

The build uses the existing local puppeteer-core, pdf-lib, pdfjs-dist,
and @napi-rs/canvas packages under portfolio_work/node_modules.
Chrome is used locally for PDF printing. No application deployment is performed.
Preview PNGs are rendered from the resulting PDF, not from the HTML source.
