# OrderSpace FileSpace Desktop

Windows-клиент синхронизации FileSpace.

## Возможности MVP

- вход с обычной учётной записью CRM;
- защищённое хранение JWT через Windows DPAPI (`safeStorage`);
- выбор локальной папки;
- первичная синхронизация с постраничным snapshot API;
- получение серверных изменений каждые 10 секунд;
- наблюдение за локальной папкой;
- загрузка новых файлов и новых версий;
- синхронизация переименований и перемещений файлов;
- безопасные конфликтные копии;
- перенос удалённых сервером файлов в корзину Windows;
- работа в системном трее и автозапуск;
- восстановление соединения после сна и временных сетевых ошибок;
- проверка, скачивание и запуск обновлений через защищённый backend.

Корневые папки пространств не следует переименовывать локально. Выборочная синхронизация будет добавлена отдельным этапом.

## Windows installer

```powershell
npm run dist:win
```

Установщик появляется в `dist/`. Для публичного распространения потребуется сертификат подписи кода Windows; локальную тестовую сборку можно устанавливать без него после подтверждения предупреждения SmartScreen.

На сервер копируется файл `OrderSpace-FileSpace-Setup-<версия>.exe`. Настройки
backend должны указывать на каталог с установщиком и ту же версию:

```env
FILESPACE_DESKTOP_DIR=/home/nodeapp/filespace-desktop/dist
FILESPACE_DESKTOP_VERSION=0.1.6
```

Клиент проверяет обновление после запуска, входа и пробуждения, а затем каждые
шесть часов. Установщик скачивается с JWT, проверяется по SHA-256 и только после
этого запускается.
